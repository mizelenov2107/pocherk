# Приёмка заметки

Сервис не отдаёт пользователю то, что не прошло автоматическую приёмку. Проверки идут после
генерации и до показа; заметка, не прошедшая проверку, уходит на пересборку один раз, а
затем показывается с честной пометкой о том, что именно не сошлось.

## Слой 1. Структура

| Проверка | Условие |
|---|---|
| Фронтматтер | все обязательные поля на месте, `презентация` принимает одно из трёх значений |
| Порядок разделов | совпадает с доктриной, лишних разделов нет |
| Плотность разделов | 4–14 содержательных разделов на 90 минут аудио |
| Служебные разделы | «Состояние источника» и «Ошибки и расхождения» присутствуют всегда |
| Глоссарий | каждый термин, выделенный в тексте полужирным как определяемый, есть в глоссарии |

## Слой 2. Приём «Другими словами»

| Проверка | Условие |
|---|---|
| Покрытие | у каждого определения есть блок; исключения только из списка доктрины |
| Три части | в блоке есть перевод, пример с числами и граница |
| Пример с числами | в блоке встречается хотя бы одна формула или число |
| Не пересказ | доля слов блока, отсутствующих в самом определении, не ниже порога |
| Сквозной набор примеров | функции в блоках берутся из набора дисциплины, а не разные каждый раз |

Проверка «не пересказ» — та самая, что ловит главный способ халтуры генератора: переставить
слова определения и выдать за объяснение.

## Слой 3. Язык

Прогон готовым инструментом автора (`yazyk.py`, жанр `konspekt`): коридоры по медианной длине
предложения, доле «мы»- и «вы»-голоса, доле причинных связок, тире-связке и двоеточию,
плюс чёрный список оборотов. Срабатывание запрета блокирует выдачу, выход за коридор идёт
пометкой в служебный раздел.

## Слой 4. Сверка с источником

Главный риск продукта — правдоподобная выдумка. Поэтому:

| Проверка | Условие |
|---|---|
| Привязка | каждый содержательный абзац несёт ссылку на фрагмент источника (таймкод аудио, страница рукописи, слайд) |
| Безоснóвные утверждения | абзац без привязки к источнику помечается и в заметку не идёт |
| Формулы | формула, которой нет ни в рукописи, ни в слайдах, помечается как восстановленная по речи |
| Числа | числовые значения сверяются с фрагментом дословно |

Привязка к источнику работает и как функция для пользователя: у каждого куска заметки видно,
откуда он взялся, и можно послушать это место записи.

## Слой 4а. Покрытие источника

Измерено на реальной лекции: определитель речи потерял одиннадцать минут середины записи и
сделал это молча, а счётчик страниц у распознавателя рукописи разошёлся на один файл из
шести, и отчёт всё равно пришёл как полный. Оба случая дороже неверной буквы: материал не
попал в конспект, а пользователю никто не сказал.

| Проверка | Условие |
|---|---|
| Таймлайн аудио | расшифровка покрывает запись; необъяснённая тишина дольше шести секунд помечается и уходит на добивание фиксированными окнами |
| Счётчик страниц | число страниц на входе равно числу распознанных страниц; расхождение блокирует выдачу |
| Уровень записи | тихая запись усиливается до определения речи, иначе определитель находит проценты речи вместо всей |
| Залипания | подряд идущие одинаковые реплики ловятся отдельно и в заметку не идут |

## Слой 5. Рукопись

| Проверка | Условие |
|---|---|
| Уверенность | доля строк с низкой уверенностью распознавания ниже порога, иначе страница уходит на переснятие |
| Правки пользователя | принятая правка дописывается в персональный ключ почерка |
| Кроп рядом | у каждой правки показывается вырезанный кусок исходной страницы |
