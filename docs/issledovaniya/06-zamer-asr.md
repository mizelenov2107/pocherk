# Замер ASR на русской академической речи: Whisper large-v3 против GigaAM v3

Дата: 2026-09-08. Материал: запись вузовской лекции по матанализу, 1 курс
(81 мин, 16 кГц моно; сама запись и конспект-эталон в репозиторий не входят).
Эталон: раздел «Терминология» и полужирные определения конспекта этой лекции.

Все цифры ниже посчитаны скриптами замера
(`etalon.py`, `analyze.py`, `run_gigaam.py`, `run_gigaam2.py`; выводы — `analiz.txt`,
`citaty.txt`, `latinica.txt`, `etalon_split.txt`), сами скрипты в репозиторий не вошли.

---

## 1. Что удалось поставить и на какие грабли пришлось наступить

GigaAM v3 поднялся, пакет и веса встали без проблем:

- `onnx-asr` 0.12.0 из PyPI, extras `[cpu,hub]`, venv на Python 3.14.7;
- модель называется **`gigaam-v3-e2e-rnnt`** (E2E-версия сама расставляет
  пунктуацию и нормализует числа), VAD — `silero`;
- веса тянутся с Hugging Face, 5 файлов, загрузка ~20 с.

Ловушек оказалось четыре, и три из них ломают замер молча.

**1. CoreML роняет энкодер.** Провайдер по умолчанию на этой машине —
CoreMLExecutionProvider, и на первом же длинном чанке он падает:

```
onnxruntime.capi.onnxruntime_pybind11_state.Fail: [ONNXRuntimeError] : 1 : FAIL :
Non-zero status code returned while running ..._CoreML_..._5 node.
Status Message: Error executing model: Unable to compute the prediction using a
neural network model.
```

Лечится явным `providers=["CPUExecutionProvider"]` и для модели, и для VAD.

**2. Запись тихая настолько, что VAD её не видит.** Диктофон лежал в зале,
лектор говорит без микрофона. Замеренные уровни исходного файла:

| величина | значение |
|---|---|
| глобальный RMS | 0.0050 (≈ −46 dBFS) |
| перцентиль 99.9 амплитуды | 0.037 |
| RMS по 5-секундным окнам | 0.0028–0.0158 |

На таком сигнале Silero VAD при пороге 0.5 находит **188 с речи из 4869**, то есть
3.9 %. Прогон формально отрабатывает и выдаёт 90 сегментов, из которых 30 пустых —
и это выглядит как «модель плохая», хотя модель тут ни при чём. Лечится
нормализацией: копия аудио усилена в 13.3 раза (`p99.9 → 0.5`, клиппинг 0.017 %
отсчётов), после чего VAD при пороге 0.35 находит 3464 с речи из 4869.

Оригинал пользователя не тронут, усиленная копия лежит в песочнице
(`audio_norm.wav`).

**3. Silero теряет одиннадцать минут середины даже на нормализованном аудио.**
Это главная находка прогона. Разбивка слов по минутам показала провал:

| минуты | слов у whisper | слов у gigaam (только VAD) |
|---|---|---|
| 22 | 72 | 10 |
| 23 | 71 | 8 |
| 24–31 | 74, 111, 59, 106, 50, 67, 59, 91 | 0 во всех |
| 32 | 59 | 5 |
| 33 | 96 | 0 |

Уровень сигнала там нормальный (RMS нормализованного аудио 0.038–0.101), то есть
дело не в громкости — Silero просто держит вероятность речи ниже порога. Проверка
в лоб: тот же GigaAM, запущенный на фиксированных 18-секундных окнах из этого
окна **без VAD**, распознаёт всё чисто:

```
[26:20] Разница двух множеств. Это у нас множество A, это у нас множество B.
        А ещё иногда считается A без Б. То есть это элементы множества A,
        которые не содержат множества B.
[27:00] Далее. Дополнение. Вот такая чёрточка на допустим, мы считаем, что наше
        множество a содержится в каком-то большом множестве.
```

То есть терялся весь блок операций над множествами — «разность», «дополнение»,
«симметрическая разность», «декартово произведение». Поэтому итоговый прогон
сделан **гибридным**: сегменты VAD плюс добивка всех дыр длиннее 6 с окнами по
18 с с нахлёстом 1 с. Ниже в таблицах есть обе колонки, чтобы видно было цену
этой ловушки.

**4. Галлюцинации на тишине.** У GigaAM они выражаются не выдуманным текстом, а
пустыми сегментами: 69 пустых из 458 в гибридном прогоне (135 с аудио). Это
безопаснее, чем поведение Whisper, — см. раздел 4.

Время: гибридный прогон 458 чанков занял 144 с на CPU (M-серия) при 81 минуте
аудио. Прогон только по VAD занял 831 с при меньшем объёме, поэтому чистым
бенчмарком скорости этот замер считать нельзя, цифры приведены как есть.

## 2. Эталон и сравнение по терминам

Раздел «Терминология» конспекта даёт **52 термина**. Но сам конспект в разделе
«Состояние источника» говорит, что четырёх разделов на паре не дошли (точные
грани, конечные и бесконечные множества, счётные и континуальные, теорема
Кантора — Бернштейна), а декартова степень, неравенство Бернулли и аксиома
полноты добавлены по презентации. Запись это подтверждает: последняя реплика на
1:20:46 — «Ну всё тогда, остальное следующую лекцию».

Поэтому честный знаменатель — **38 терминов, которые на записи действительно
звучали**; остальные 14 не мог найти ни один движок, и в проценты они не идут.

| | whisper large-v3 | gigaam (только VAD) | gigaam (гибрид) |
|---|---|---|---|
| **терминов из 38 озвученных** | **24** | 23 | **28** |
| слов в транскрипте | 6306 | 6071 | 7612 |
| сегментов | 984 | 382 | 458 |
| пустых сегментов | 0 | 87 | 69 |
| латинских токенов | 133 | 151 | 207 |
| греческих букв и матзначков | **0** | **0** | **0** |
| серий залипаний | 6 | 0 | 1 |
| сегментов внутри залипаний | 12 | 0 | 2 |
| «титровые» галлюцинации | 4 | 0 | 0 |

Пересечение по найденным терминам: 23 термина нашли оба.
Только whisper — «декартово произведение».
Только gigaam — «база индукции», «комплексные числа», «пустое множество»,
«разность», «симметрическая разность».

**Не узнал никто (10 терминов):** квантор, квантор общности, квантор
существования, диаграммы Эйлера — Венна, сюръекция, биекция, плотность,
иррациональность, доказательство от противного, декартово произведение (у
gigaam).

Показательно, как рушится слово «квантор» — центральный термин первого получаса:

```
WHISPER [0:14:22] То есть если мы отрицаем квантовую общность, мы его заменяем
                  на существую.
GIGAAM  [0:14:10] А квантовы у нас меняются в отрицании на противоположные.
                  То есть, если мы отрицаем квантов всеобщности, мы его
                  заменяем на существо.
```

Оба слышат «квантовый» и «квантов» вместо «квантор». Ни один транскрипт не
даёт слова, по которому термин можно было бы найти поиском.

То же с сюръекцией:

```
WHISPER [0:46:54] вложение или инъекция, наложение или сурьекция.
WHISPER [0:52:59] А какая функция будет тогда сюрреективной?
GIGAAM  [0:46:51] вложения или инъюкция, наложение или субъекция
GIGAAM  [0:50:24] когда вас просят проверить функцию на субъективность
```

«Субъективность» вместо «сюръективности» — характерная подмена GigaAM: он тянет
редкий математический термин к частотному общеязыковому.

## 3. Латиница и греческие буквы внутри русской речи

Это то, ради чего замер делался, и здесь результат однозначный.

### Греческих букв и кванторных значков нет ни у кого

**Оба движка выдали ровно 0 греческих букв и 0 математических значков** на всю
81 минуту. Кванторы, которые лектор проговаривает вслух десятки раз, оба
записывают русскими словами:

| произносится | должно быть | whisper: значком / словами | gigaam: значком / словами |
|---|---|---|---|
| «для любого» | ∀ | 0 / 8 | 0 / 14 |
| «существует» | ∃ | 0 / 13 | 0 / 13 |

Эпсилон в этой лекции просто не звучал (0 совпадений и по символу, и по слову в
обоих транскриптах), так что по нему замер ничего не показал — проверять надо на
лекции про пределы.

### Латинские буквы: gigaam заметно лучше, но непоследователен

| обозначение | символ | whisper: символом / кириллицей | gigaam: символом / кириллицей |
|---|---|---|---|
| «эн» | N | 4 / 0 | **24** / 0 |
| «зет» | Z | 0 / 0 | 1 / 0 |
| «ку» | Q | 0 / 0 | 0 / 0 |
| «эр» | R | 10 / 0 | 1 / 0 |
| «эф» | f | 6 / 0 | **18** / 0 |
| «гэ» | g | 2 / 8 | 0 / 8 |
| «икс» | x | 25 / 0 | **61 / 25** |
| «игрек» | y | 11 / 0 | **2 / 30** |
| «а», «бэ» | A/B | 5 / 0 | **51** / 0 |

Ключевое: gigaam ставит латиницу втрое чаще (207 токенов против 133), и на
именах множеств A, B, X, N он почти безошибочен. Но у него **разъезжается одна и
та же буква внутри одного предложения**, и особенно плох «игрек» — 30 раз
кириллицей против 2 раз буквой:

```
GIGAAM [0:35:59] Соответствие из многие X множества игрек мы называем любое
                 подмножество произведения X на игрек.
GIGAAM [0:40:42] образ F отки такие, что существуют иксы из множества A,
                 для которых F от X равно игрек.
GIGAAM [0:13:06] Это означает, что для любого икс из множества D <...>
                 То есть для любого X любой икс удовлетворяет условию p.
```

В последней цитате одна и та же буква в одном предложении записана и как «икс»,
и как «X».

Хуже того, нормализатор GigaAM иногда выдаёт **транслит русского названия буквы
латиницей** — мусор, которого нет ни в одном алфавите:

```
[0:38:26] Прямую параллельную оси igrek мы найдём только одно пересечение
[0:42:31] F из X в игрек работает, а F минус первый из Yek в X
[0:45:09] допустим, у вас функция grek равна X в квадрате
[0:34:15] во втором модуле мы уйдём X ix Z
[0:43:07] A и B— это под множество X is, да?
[0:50:24] важно обращать внимание на то, как заданы множества X/ in igr
[0:13:06] любой икс удовлетворяет условию pex
```

`igrek`, `grek`, `Yek`, `igr`, `ix`, `is`, `pex` — это латинская запись русских
слов «игрек», «икс», и она ломает любой автоматический разбор сильнее, чем
честная кириллица.

Whisper ведёт себя иначе: он ставит меньше латиницы, но там, где ставит, реже
мешает регистр — зато **подменяет саму букву**. Функция `f` у него систематически
превращается в `S` и в `R`:

```
WHISPER [0:42:05] S у нас в одну сторону действует, да?
WHISPER [0:42:15] S-1, S-2.
WHISPER [0:42:31] То есть S из Y работает, а S-1 из Y.
GIGAAM  [0:42:31] То есть F из X в игрек работает, а F минус первый из Yek в X.

WHISPER [0:44:07] применили функцию R и получили такие цифры, множество И.
GIGAAM  [0:44:00] применили функцию F и получили такие-то игреки из множества игрек.

WHISPER [0:39:37] множество z, это множество x
GIGAAM  [0:39:25] Множество D— это множество X таких существует F.

WHISPER [0:41:14] df, df и х, и х.  /  [0:41:16] df это подножие на некоторое х.
```

И отдельно — у Whisper слово «множество» регулярно превращается в «умножить»,
что убивает целый блок:

```
WHISPER [0:26:24] Это умножить в множество b.
WHISPER [0:26:31] То есть это элемент умножить в множество а,
WHISPER [0:26:34] который не содержит умножить в множество b.
GIGAAM  [0:26:27] А ещё иногда считается A без Б. То есть это элементы
                  множества a, которые не содержатся во множестве.
```

**Вывод по разделу.** Латиницу лучше держит GigaAM, но ни один движок не даёт
готового к употреблению текста: греческих букв и кванторных значков нет вообще,
а латинские буквы у GigaAM непоследовательны по регистру, по выбору кириллица
или латиница и иногда транслитерированы.

## 4. Залипания и галлюцинации

**Whisper** даёт классические для него титровые галлюцинации на тишине:

```
[0:02:30] то до конца недели, пожалуйста, включите несколько субтитров.
[0:28:24] Субтитры делал DimaTorzok
[0:54:59] Субтитры делал DimaTorzok
[1:21:04] Продолжение следует...
```

Плюс 33 сегмента, состоящих целиком из одного слова «Спасибо», «Вот» или «Да»
(одно только «спасибо» — 16 раз), и 6 серий залипаний по 2 сегмента:

```
x2  0:25:20–0:25:29  'Это иллюстрация, когда множество В содержится в множестве А.'
x2  1:16:43–1:17:13  'Если вы строгий, то это будет верно.'
```

**GigaAM** титровых галлюцинаций не даёт вовсе — 0 совпадений по маркерам
«субтитры / продолжение следует / DimaTorzok». Залипание одно, на 2 сегмента
(«Угу» на 0:00:35). Расплата — 69 пустых сегментов: на тишине он честно молчит,
но вместе с тишиной иногда режет и начало фразы.

Замечание конспекта «залипаний распознавания в записи нет» скриптом не
подтверждается: у Whisper их 6 серий на 12 сегментов. Они короткие (по 2
повтора), поэтому глазами при вычитке не бросились в глаза.

## 5. Продиктованные формулы

Формульные маркеры по всему транскрипту:

| | whisper | gigaam (гибрид) |
|---|---|---|
| цифр | 122 | 28 |
| знак `+` | **0** | **11** |
| «плюс» словом | 19 | 8 |
| «равно» словом | 24 | 31 |
| «в степени» | 5 | 5 |
| «больше либо равно» | 3 | 7 |

Whisper вообще не ставит знак `+`, GigaAM ставит его 11 раз. Зато Whisper чаще
переводит числительные в цифры. По существу же важнее, кто не переврал сам
разбор. Пять фрагментов рядом:

**1. База индукции для $2^n \geqslant n+1$ (1:10:40).** Whisper искажает
неравенство, GigaAM берёт верно.

```
WHISPER  Так, проверим важный инфекция. Вместе n подставляем 1. Вот он, что было.
         2 в первой степени больше равно чем 1 в первой степени.
         Ну да, 2 больше равно чем 2.
GIGAAM   Так, проверим базу индукции вместе N подставляем единицу. Смотрим, что
         получится. Два в первой степени больше равно, чем 1+ 1.
```

«1 в первой степени» вместо $1+1$ — правая часть неравенства подменена, и
«важный инфекция» вместо «базу индукции» тоже.

**2. Запись шага (1:11:51).**

```
WHISPER  Давайте запишем 2 в степени n плюс 1. И будем строить нашу мерамер.
GIGAAM   Как действовать? Давайте запишем: два в степени N+1.
         И будем строить наше неравенство.
```

**3. Вывод шага (1:12:45).** Оба дают текст, из которого выкладка
восстанавливается, GigaAM — компактнее и с `+`.

```
WHISPER  Значит, мы n отбросим, от этого наше значение быстро уменьшится.
         Больше ли равно, чем n плюс 2. <...> 2 в степени n плюс 1
         больше липравного, чем N плюс 2.
GIGAAM   Если мы N отбросим, от этого наше значение больше либо равно, чем N+
         эта часть, в которую мы подставили N+1. То есть вот мы получили наше
         неравенство: 2 в степени Н1 больше либо равно, чем N+2.
```

У GigaAM «Н1» — кириллическая Н вместо латинской N, ровно та же болезнь.

**4. Иррациональность корня из двух (1:06:31).** Whisper теряет логику целиком.

```
WHISPER  То есть оно рациональное. Если что рациональное, значит оно
         присоединяется к противодружию. Тогда можно предполагать, что это
         корень из двух равно какой-то m на n. Ну, по-настоящему. По-настоящему.
GIGAAM   То есть оно рационально. Если число рациональное, значит, оно в виде
         сократиной дроби, да? Тогда мы можем утверждать, что это корень из двух
         равно какое-то M на.
```

«присоединяется к противодружию» — это «записывается в виде несократимой дроби».

**5. Пример $y = x^2$ с образом и прообразом (0:45:09).**

```
WHISPER  Допустим, у вас х, у равно x2. А допустим, мы множество а зададим как
         1 и 2. <...> Нам нужно 1 и 2 в числе квадратных.
         Это будет значить множество 1 и 4.
GIGAAM   Ну, допустим, у вас функция grek равна X в квадрате, да? А допустим,
         мы множество A зададим как отдельно. <...> Нам нужно один и два
         возвести в квадрат. Это будет, значит, множество 1 и 4.
```

Whisper даёт `x2` вместо $x^2$ (степень потеряна), GigaAM — «X в квадрате»
словами, но с правильной латинской X; зато «функция grek» вместо $y$.

**Итог по формулам.** Ни один транскрипт не даёт формулы, готовой к сборке в
LaTeX без обращения к доске. Но GigaAM реже переворачивает смысл неравенства и
чаще сохраняет структуру выкладки; Whisper на формульных кусках срывается в
бессмыслицу («мерамер», «противодружие», «важный инфекция»).

## 6. Вывод: что брать и что чинить вторым проходом

**Брать GigaAM v3 E2E RNN-T через `onnx-asr`, но обязательно с обвязкой.**
На честном знаменателе он даёт 28 терминов из 38 против 24 у Whisper large-v3,
втрое чаще ставит латинские обозначения, не выдумывает титры и почти не залипает.
Он же лучше держит длинные связные фразы: 458 сегментов против 984 у Whisper при
большем объёме текста, то есть меньше рваных обрывков.

Обвязка, без которой замер и продакшн одинаково бессмысленны:

1. **Нормализовать усиление перед VAD.** Записи с диктофона из зала идут на
   −46 dBFS, и Silero на них слепнет (3.9 % найденной речи). Считать `p99.9`
   амплитуды и тянуть его к 0.5.
2. **Прибивать провайдер к CPU.** CoreML на энкодере GigaAM падает.
3. **Не доверять VAD в одиночку.** Silero потерял 11 минут подряд на нормальном
   по громкости фрагменте. Все дыры длиннее ~6 с добивать фиксированными окнами
   по 18 с с нахлёстом. Это дало +5 терминов и +1541 слово.
4. **Резать с запасом по краям**: `speech_pad_ms=200` вместо дефолтных 30.

Что придётся чинить вторым проходом — то есть слоем нормализации поверх ASR:

- **Кванторы и греческие буквы восстанавливать целиком.** Их нет в выдаче в
  принципе: 0 значков ∀ и ∃ на 27 произнесённых кванторов. Второй проход должен
  переводить «для любого» → ∀, «существует» → ∃ по контексту формулы.
- **Приводить обозначения к одной букве.** Один и тот же объект приходит как
  `X`, «икс», `ix`, `is`; `y` — как «игрек» (30 раз), `Y` (2 раза), `igrek`,
  `grek`, `Yek`, `igr`. Нужен словарь имён букв (икс, игрек, зет, эн, эф, гэ,
  эль, эр, ку) с транслитерационными вариантами и приведение к латинице.
- **Чинить кириллическую Н вместо латинской N** и подобные гомоглифы — GigaAM
  пишет «2 в степени Н1».
- **Восстанавливать терминологию по глоссарию темы.** Десять терминов не берёт
  никто: квантор («квантовый», «квантов»), сюръекция («субъекция»,
  «субъективность»), биекция, диаграммы Эйлера — Венна, плотность,
  иррациональность. Это лечится не движком, а списком терминов недели, который
  у нас и так есть в конспектах, — подставлять по фонетической близости.
- **Собирать формулы по доске, а не по звуку.** Ни один движок не дал степень
  как степень (`x2` у Whisper, «X в квадрате» у GigaAM). Формулы всё равно
  сверяются со снимками доски.
- **Whisper остаётся полезен как второй источник** там, где GigaAM молчит:
  у него 0 пустых сегментов против 69, и «декартово произведение» нашлось только
  у него. Дешёвый вариант — гонять оба и склеивать по таймкодам.

Отдельно: замечание конспекта «залипаний распознавания в записи нет» неверно,
у Whisper 6 серий на 12 сегментов. Стоит поправить при следующей правке заметки.
