# Почерк

Сервис, который превращает материалы одного курса (запись лекции с диктофона, фото рукописного конспекта, слайды и PDF учебника) в связное дерево заметок, где у каждого абзаца виден источник: таймкод записи, страница тетради или номер слайда.

**Стадия: исследование и каркас.** В репозитории лежат шесть исследований и два замера, которые предшествовали коду, план работ с гейтами и первая часть конвейера (очередь, квоты, распознавание речи и выправление обозначений). Интерфейса пока нет, на главной странице стоит заглушка.

## Стек

Next.js 16 (App Router) + React 19, TypeScript, PostgreSQL через Prisma 7, очередь задач pg-boss, zod, rate-limiter-flexible. Распознавание речи — GigaAM v3 (RNN-T) через `onnx-asr` и Silero VAD в отдельном Python-процессе, ffmpeg для приведения аудио.

## Архитектура

- `prisma/schema.prisma` — модель данных: пользователи и сессии, подписка и журнал квот, курсы, источники и файлы, задачи конвейера, фрагменты с провенансом, темы, заметки с версиями и цитатами, термины, профиль почерка.
- `src/lib/ochered.ts` — постановка задач в pg-boss в той же транзакции, что и запись в базе.
- `src/lib/kvota.ts` — квота и потолок расходов. Объём считается до постановки задачи (ffprobe, pdfinfo), а проверка остатка и списание идут одним атомарным запросом.
- `worker/index.ts` — работник конвейера. Стадии идемпотентны по паре «источник и стадия», поэтому падение часовой записи на середине не оплачивает уже сделанное второй раз.
- `worker/asr/raspoznat.py` — распознавание с тремя измеренными обходами: нормализация уровня перед VAD (запись с задней парты идёт на −46 дБ, и VAD без неё находит около 4 % речи), явный CPU-провайдер (CoreML роняет энкодер) и добивка окнами всех дыр VAD длиннее 6 с.
- `src/lib/oboznacheniya.ts` — детерминированное восстановление обозначений в расшифровке («икс» → `x`, `igrek` → `y`), без модели и с проверочным скриптом.
- `scripts/` — проверки очереди, квот и обозначений и прогон аудио через весь конвейер.

Главный результат замера ASR: на честном знаменателе GigaAM v3 распознал 28 терминов из 38 против 24 у Whisper large-v3, втрое чаще ставил латинские обозначения и не выдумывал титры. При этом кванторов и греческих букв в выдаче нет ни у одного движка, и их восстанавливает второй проход.

## Запуск

```bash
npm install
cp .env.example .env            # DATABASE_URL на свой PostgreSQL
npx prisma migrate dev
npm run dev                     # веб на :3000
npm run rabotnik                # работник конвейера
pip install -r worker/asr/requirements.txt   # для стадии распознавания
npm run progon:audio -- запись.m4a           # прогон одной записи через конвейер
```
